# 桌面图标一键更换器

桌面图标一键更换器是一款专为 Windows 打造的轻量、免安装个性化桌面管理与美化工具。程序以单个可执行文件运行，体积仅约 358 KB，无需安装且不常驻后台，全面涵盖快捷方式、常规文件夹以及 EXE 程序图标更换，并集成了批量风格统一、系统原生图标库、桌面图标位置记忆与右键菜单快速入口。

---

## 一、 功能概述

1. **三合一目标支持**
   - **快捷方式 (.lnk)**：直接修改快捷方式图标，毫秒级生效，支持一键还原官方原版图标。
   - **常规文件夹**：通过配置隐藏的 desktop.ini 实现文件夹个性化外观，支持一键还原。
   - **EXE 可执行程序**：利用 Windows 原生 PE 资源更新技术，直接替换 `.exe` 内部的内置图标资源，修改前自动建立安全备份，支持一键无损还原。

2. **桌面快捷方式批量风格统一**
   - 支持多选拖入或一键扫描桌面所有快捷方式。
   - 可一键批量统一应用为 macOS Squircle 大圆角、正圆徽章或极简纯白单色风格，桌面瞬间整齐划一，强迫症福音。

3. **Windows 原生精选高清图标库**
   - 免除上网到处搜图找图的麻烦，直接从微软 Windows 核心库中精选提取数十款 256x256 官方高清图标（包含系统设备、现代文件夹、媒体娱乐、开发工具等），点击即可直接应用。

4. **桌面图标排列位置一键备份与恢复**
   - 解决因运行全屏游戏切换分辨率、外接显示器插拔或系统异常导致的桌面图标乱飞问题。
   - 支持一键精确记忆当前桌面所有图标的网格像素坐标，打乱后点击恢复即可瞬移归位。

5. **系统右键菜单快速集成 (绿色无残留)**
   - 支持在快捷方式、文件夹或 EXE 上右键直接点击“一键更换图标”，自动调起本工具并填入目标。
   - 写入当前用户注册表 (HKCU)，无需管理员权限，随时可在软件内一键彻底注销清理，零系统残留。

6. **全局智能盲拖防呆分流**
   - 具备自适应文件特征识别能力。无论将图片还是待修改的快捷方式/文件夹/EXE 拖入左卡槽、右卡槽或窗口任意空白处，均会自动放入正确卡槽，杜绝拖错报错。

7. **可视化正方形裁剪与美化特效滤镜**
   - 导入非正方形图片自动激活裁剪，支持鼠标滚轮无级缩放、双击快速重置居中。
   - 提供 3 种几何外形预设：原生直角、macOS 大圆角 (平滑抗锯齿)、正圆形。
   - 内置修饰滤镜：12% 呼吸感留白边距、微立体环境阴影、单色扁平剪影模式（纯白/极夜黑）。

8. **剪贴板直接粘贴 (Ctrl + V)**
   - 网页复制图片或截图后，在软件窗口内按 Ctrl + V 即可直接载入为新图标，无需提前保存为本地文件。

9. **安全隐藏 / 恢复快捷方式小箭头**
   - 采用 Windows 原生透明遮罩注册表机制隐藏或恢复小箭头，不破坏系统文件关联。
   - 采用纯净的系统广播通知，绝不杀死资源管理器系统进程，保证系统 100% 稳定安全。

10. **7 种全分辨率 ICO 生成与高分屏优化**
    - 自动将图像转换为内嵌 16, 32, 48, 64, 96, 128, 256 像素共 7 种标准分辨率的高清 ICO 文件，在 2K/4K 高分屏（125%、150% 等缩放比例）下呈现极致锐利质感。
    - 图标自动持久化归档至系统应用数据目录，原图删除后不影响已生效的桌面图标。

## 三、 详细操作指南

### 1. 单个图标极速更换
1. 打开 `桌面图标一键更换器.exe`。
2. 从桌面或文件夹中，将需要修改的快捷方式、文件夹或 `.exe` 程序直接拖入软件（随手拖入窗口任意区域均可自动识别放入左侧目标卡槽）。
3. 确定新图标来源（三选一）：
   - **直接拖图**：将图片拖入软件（或截图后在软件窗口按 Ctrl + V）；
   - **从现有软件提取**：将任意 `.exe` 或 `.dll` 拖入软件提取其官方原版高清图标；
   - **使用系统精选库**：点击右侧卡槽中的“系统精选图标库”，在分类网格中挑选心仪图标直接确定。
4. 若载入了图片，在弹出的裁剪窗口中微调构图、外形风格（直角/圆角/正圆）及微阴影，点击“完成裁剪”。
5. 点击底部的“一键替换桌面图标”，桌面即刻毫秒级同步刷新。

### 2. 桌面快捷方式批量统一风格
1. 点击顶部工具栏的“批量统一风格”按钮。
2. 点击右上角“一键载入桌面全部快捷方式”，或手动将多个快捷方式拖入列表中。
3. 选择统一风格（例如：macOS Squircle 大圆角 + 12% 呼吸感留白 + 立体微阴影）。
4. 点击底部的“开始一键批量统一风格”，软件自动后台完成全套生成并统一刷新桌面。

### 3. 桌面图标排列位置记忆与复原
1. **备份位置**：当桌面图标排版满意时，点击顶部工具栏的“桌面图标位置”，选择【是】即可将当前所有图标坐标记录入配置文件。
2. **复原归位**：当屏幕分辨率改变或桌面图标被意外打乱时，点击“桌面图标位置”，选择【否】即可让所有图标精确归位。

### 4. 开启系统右键菜单快速入口
1. 点击顶部工具栏的“右键菜单集成”，状态变为“已集成右键菜单”。
2. 此时在桌面任意快捷方式、文件夹或 .exe 文件上鼠标右键，菜单中将直接出现“一键更换图标”选项，点击即可自动启动本工具并载入该目标。
3. 若不再需要，再次点击该按钮即可彻底清除注册表项，干净无痕。

### 5. 恢复官方原版默认图标
1. 将已修改过的快捷方式、文件夹或 EXE 程序拖入左侧卡槽。
2. 点击左侧卡槽下方的“重置为官方原版软件图标”或“恢复原始内置 .exe 图标”。
3. 目标对象将立即通过安全备份或系统机制无损恢复初始状态。

## 四、 常见问题解答 (FAQ)

**问题 1：直接替换 EXE 内置图标安全吗？**  
回答：安全。软件在修改任何 `.exe` 文件的内置 PE 资源前，均会在系统应用数据目录创建一份完整安全备份。如果后续希望恢复，只需将该 `.exe` 再次拖入本软件，点击恢复按钮即可一键还原。

**问题 2：修改 EXE 时提示目标程序正在运行怎么办？**  
回答：软件内置进程写锁保护检测。若目标程序正在运行，软件会主动弹出友好提示引导退出程序。请在任务栏或任务管理器中关闭该程序后，在提示框中点击确定即可继续完成修改。

**问题 3：隐藏或恢复快捷方式小箭头会导致桌面黑屏或卡顿吗？**  
回答：不会。本软件彻底摒弃了强杀资源管理器进程（kill explorer）的暴力做法，全程采用微软官方标准的透明遮罩与 Shell 广播接口，安全无感，系统 100% 绝对稳定。

**问题 4：更换图标后，如果删除了下载的原图片，图标还会显示吗？**  
回答：正常显示。软件在应用图标时已自动将图片转为标准 7 尺寸 ICO 文件并集中归档至系统应用数据目录，原图删除后没有任何影响。

**问题 5：开启右键菜单需要以管理员身份运行吗？**  
回答：不需要。本软件右键菜单严格写入当前用户注册表分支 (HKCU)，无需 UAC 提权，不污染全局系统，用户随时可以一键关闭。
